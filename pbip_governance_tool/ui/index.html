How it works
  • Opens Microsoft Edge with its own profile (your normal Edge is untouched). The first time, sign in to Power BI in that window - it stays signed in for later runs.
  • Opens the report once as a warm-up (not counted), then opens every page by its link, round-robin, for the number of loads you chose.
  • Reads the same network data as F12 > Network: every visual query request (xhr), skipping preflight rows, until queries stop arriving for 5 seconds.
  • Page load = the page's slowest visual query - the top "query" row when you sort the Network tab by Time. Queries run in parallel, so queries of 0.5 s, 1 s and 1.5 s mean the page loaded in 1.5 s. Power BI's own start-up time isn't included.
  • Each page is measured in its default state. Pop-ups or views behind bookmark buttons aren't clicked, and drillthrough pages open without a selection.
  • Results are saved automatically as a CSV in the perf_results folder next to this app.
